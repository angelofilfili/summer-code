# Contact Book

This project will be inclusive of all the week 1 and week 2 topics I have learned/refreshed on so far.

This project is a simulation of a contact book using functions, conditionals, loops, classes, lists, dictionaries, writing/reading files, and modules.

## How to Run
1. Clone the repo
2. Navigate to the Contact_Book folder
3. Run: python main.py

The project has 5 features which are 
1. Adding a contact
2. Viewing all the contacts
3. Searching a contact using a name
4. Removing a contact
5. Quitting the simulation

After every use of a feature it is saved including between runs if you decide to quit.

What I learned:
I learned how to incorporate python basics into a full working simulation allowing users to have an accesible contact book, how to write and read json files, and how to use modules created by python and myself.
